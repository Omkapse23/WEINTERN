
# Banking Application

## 1. Project Title
Banking Application

## 2. Objective
To develop a simple console-based Banking Application using Java that allows users to perform basic banking operations.

## 3. Features Implemented
- Create a bank account.
- Deposit money.
- Withdraw money.
- Check account balance.
- Display account details.

## 4. Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- VS Code

## 5. File Structure
```text
Task-2-Banking-Application
│
├── src
│   ├── BankAccount.java
│   ├── BankingApp.java
│   └── Main.java
│
├── bin
└── README.md
```

## 6. Steps to Compile and Run
1. Open the project in VS Code.
2. Open the terminal in the project folder.
3. Compile the Java files.
4. Run the Main class.
5. Follow the instructions displayed in the console.
