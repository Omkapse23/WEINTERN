
# Collections Challenge

## 1. Project Title
Java Collections Challenge

## 2. Objective
To understand and implement the Java Collections Framework using ArrayList, HashMap, and Queue for storing and managing data.

## 3. Features Implemented
- Store and display elements using ArrayList.
- Store key-value pairs using HashMap.
- Add and remove elements using Queue.
- Perform basic collection operations.

## 4. Technologies Used
- Java
- Java Collections Framework
- ArrayList
- HashMap
- Queue
- VS Code

## 6. Steps to Compile and Run
1. Open the project in VS Code.
2. Open the terminal in the project folder.
3. Compile the Main.java file.
4. Run the Main class.
5. Check the output in the console.
