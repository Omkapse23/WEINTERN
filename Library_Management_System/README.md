
# Library Management System

## 1. Project Title
Library Management System

## 2. Objective
To develop a simple console-based Library Management System using Java that allows users to manage books and perform basic library operations.

## 3. Features Implemented
- Add books to the library.
- Display all books.
- Issue books.
- Return books.
- Check book availability.

## 4. Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- VS Code

## 5. File Structure

```text
Task-1-Library-Management
│
├── src

│   └── Main.java
│

```

## 6. Steps to Compile and Run
1. Open the project in VS Code.
2. Open the terminal in the project folder.
3. Compile the Java files.
4. Run the Main class.
5. Follow the instructions displayed in the console.
