
# Java Development Internship - Week 1 Tasks

## 1. Project Title
Java Development Internship - Week 1 Assignments

## 2. Objective
The objective of these assignments is to strengthen Java programming fundamentals, understand Object-Oriented Programming concepts, and practice the Java Collections Framework through practical console-based applications.

## 3. Projects Included

### Task 1: Library Management System
A console-based Java application for managing books and performing basic library operations.

**Key Concepts:**
- Classes and Objects
- Object-Oriented Programming (OOP)
- ArrayList
- Book management

### Task 2: Banking Application
A console-based Java application for performing basic banking operations.

**Key Concepts:**
- Classes and Objects
- Encapsulation
- Methods
- Deposit and withdrawal operations
- Balance management

### Task 3: Collections Challenge
A Java project demonstrating the use of different collections for storing and managing data.

**Collections Used:**
- ArrayList
- HashMap
- Queue

## 4. Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- VS Code
- Git and GitHub

## 6. How to Run the Projects

### Task 1: Library Management System
```bash
cd "Task-1-Library-Management"
javac -d bin src/*.java
java -cp bin Main
```

### Task 2: Banking Application
```bash
cd "Task-2-Banking-Application"
javac -d bin src/*.java
java -cp bin Main
```

### Task 3: Collections Challenge
```bash
cd "Task-3-Collections-Challenge"
javac -d bin src/*.java
java -cp bin Main
```

**Note:** Run each command from the main `WEEK-1 TASK` folder. Return to the main folder using `cd ..` before running another task.
